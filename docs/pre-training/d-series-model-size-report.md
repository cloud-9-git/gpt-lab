# D1-D6 모델 크기 비교 실험 누적 보고서

작성일: 2026-06-03

## 1. 실험 목적

이번 D1-D6 실험의 목적은 B/C 시리즈에서 고른 최적화 설정을 고정한 상태에서 모델 크기를 얼마나 키우는 것이 좋은지 확인하는 것이다.

B 시리즈에서는 `lr=1.5e-3`이 가장 좋았고, C 시리즈에서는 `drop-rate=0.05`가 가장 좋은 dropout 후보였다. 따라서 D 시리즈에서는 이 두 값을 고정하고 `emb-dim`과 `n-layers`만 바꿔 비교한다.

## 2. 고정 설정

| 항목 | 값 |
| --- | --- |
| learning rate | 1.5e-3 |
| drop rate | 0.05 |
| epochs | 4 |
| context length | 64 |

## 4. 현재 해석

D1은 `emb-dim=128`, `n-layers=2`인 작은 기준 모델이다.

final val loss는 `5.3315`, best val loss는 약 `5.3262`이다. train-val gap은 `0.1766`으로 작아서 과적합 신호는 크지 않다. 다만 validation loss 자체가 이전 C2의 `5.0798`보다 높기 때문에, 현재 설정에서는 작은 기준 모델의 표현력이 부족할 가능성이 있다.

D2는 `emb-dim=192`, `n-layers=2`인 모델이다. D1과 비교하면 layer 수는 같고 embedding 차원만 `128 -> 192`로 커졌다.

final val loss는 `5.2748`, best val loss는 약 `5.2632`로 D1보다 낮다. train loss도 `5.1549 -> 4.9702`로 내려갔다. 따라서 같은 2-layer 조건에서는 embedding 차원을 키우는 것이 validation loss 개선에 도움이 되었다.

D3은 `emb-dim=256`, `n-layers=2`인 모델이다. D2와 비교하면 layer 수는 같고 embedding 차원만 `192 -> 256`으로 커졌다.

final val loss는 `5.2257`, best val loss도 약 `5.2257`로 D2보다 낮다. train loss도 `4.9702 -> 4.8166`으로 내려갔다. 따라서 2-layer 조건에서는 embedding 차원을 `128 -> 192 -> 256`으로 키울수록 train loss와 validation loss가 모두 개선되었다.

D4는 `emb-dim=128`, `n-layers=4`인 모델이다. D1과 비교하면 embedding 차원은 같고 layer 수만 `2 -> 4`로 늘었다.

final val loss는 `5.3227`, best val loss는 약 `5.3161`로 D1보다 약간 낮다. 하지만 D2/D3보다 높기 때문에, 현재 조건에서는 작은 embedding 차원을 유지한 채 깊이만 늘리는 것보다 embedding 차원을 키우는 쪽이 더 효과적이었다.

D5는 `emb-dim=192`, `n-layers=4`인 모델이다. A/B/C 시리즈에서 주로 사용한 유력한 모델 크기이며, D3와 비교하면 embedding 차원은 작지만 layer 수가 더 많다.

final val loss는 `5.2280`, best val loss는 약 `5.2232`이다. final val 기준으로는 D3의 `5.2257`이 아주 근소하게 앞서지만, best val 기준으로는 D5가 D3보다 아주 근소하게 낮다. train-val gap도 `0.1695`로 D3의 `0.4091`보다 작아서 안정성 면에서는 D5가 더 좋아 보인다.

D6는 `emb-dim=256`, `n-layers=4`인 가장 큰 후보 모델이다.

final val loss는 `5.2234`, best val loss는 약 `5.2204`로 D 시리즈 중 가장 낮다. 하지만 D5와의 final val 차이는 약 `0.0046`, best val 차이는 약 `0.0028` 정도로 매우 작다. 반면 train-val gap은 `0.4784`로 D5보다 훨씬 크기 때문에, 같은 4 epochs 조건에서는 D6가 약간 더 강하지만 비용과 과적합 위험도 함께 커진 후보로 보는 것이 좋다.

현재까지의 결론:

> `lr=1.5e-3`, `drop-rate=0.05`, `epochs=4` 조건에서 순수 val loss 1위는 `256/4`인 D6이다. 하지만 D5 대비 개선폭이 매우 작고 train-val gap이 크게 벌어졌기 때문에, 다음 E 시리즈의 현실적인 기본 모델 크기는 `192/4`인 D5로 둔다. D6는 계산 여유가 있을 때 최종 성능 후보로 다시 확인할 수 있다.

## 5. 다음 확인 포인트

- E 시리즈에서는 D5 `emb-dim=192`, `n-layers=4`를 고정하고 context length를 다시 비교한다.
- D6는 D 시리즈의 순수 val loss 1위이지만, 개선폭이 작으므로 최종 학습 전에 계산 여유가 있을 때 장기 재검증 후보로 남긴다.
- 현재까지는 작은 모델인 D1/D4보다 D3/D5/D6가 확실히 좋으며, `128` 차원은 표현력이 부족한 편으로 보인다.
