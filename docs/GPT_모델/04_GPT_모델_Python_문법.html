1. import torch, import torch.nn as nn

torch는 tensor 계산을 위한 라이브러리입니다.

import torch

torch.nn은 neural network layer들을 모아둔 모듈입니다.

import torch.nn as nn

그래서 아래처럼 씁니다.

nn.Module
nn.Linear
nn.Dropout
nn.Parameter
nn.ModuleList
nn.Sequential

as nn은 긴 이름을 짧게 줄이는 문법입니다.

torch.nn.Linear

대신:

nn.Linear

라고 쓸 수 있습니다.

2. nn.Module 상속

PyTorch에서 모델 부품은 보통 nn.Module을 상속해서 만듭니다.

class LayerNorm(nn.Module):
    ...

뜻:

LayerNorm은 PyTorch 모델 부품이다.

nn.Module을 상속하면 좋은 점:

1. 내부 layer와 parameter를 PyTorch가 자동으로 추적합니다.
2. model.parameters()로 학습할 값들을 찾을 수 있습니다.
3. model.train(), model.eval() 같은 기능을 쓸 수 있습니다.
4. forward()를 정의하면 객체를 함수처럼 호출할 수 있습니다.

예:

ln = LayerNorm(64)
out = ln(x)

겉으로는 ln(x)처럼 보이지만, 내부적으로는:

ln.forward(x)

가 호출됩니다.

3. __init__과 forward

PyTorch 모듈에서는 보통 두 메서드가 중요합니다.

def __init__(self, ...):
    ...

def forward(self, x):
    ...

__init__

객체가 만들어질 때 한 번 실행됩니다.

ffn = FeedForward(64)

이 순간 FeedForward.__init__이 실행됩니다.

여기서는 layer를 준비합니다.

self.net = nn.Sequential(
    nn.Linear(d_model, 4 * d_model),
    GELU(),
    nn.Linear(4 * d_model, d_model),
)

forward

입력이 들어올 때마다 실행됩니다.

out = ffn(x)

이 순간 FeedForward.forward가 실행됩니다.

여기서는 실제 계산을 합니다.

def forward(self, x):
    return self.net(x)

정리:

__init__: 부품 준비
forward: 실제 계산

4. super().__init__()

nn.Module을 상속한 클래스의 __init__에서는 보통 첫 줄에 이걸 씁니다.

super().__init__()

뜻:

부모 클래스인 nn.Module의 초기화도 실행한다.

이걸 해야 PyTorch가 내부 layer와 parameter를 제대로 추적합니다.

예:

class FeedForward(nn.Module):
    def __init__(self, d_model: int):
        super().__init__()
        self.fc = nn.Linear(d_model, d_model)

super().__init__() 없이 layer를 붙이면 PyTorch 모델로서 필요한 초기화가 빠질 수 있습니다.

5. self

self는 지금 만들어진 객체 자신입니다.

self.gamma = nn.Parameter(torch.ones(normalized_shape))

이 말은:

이 LayerNorm 객체 안에 gamma라는 값을 저장한다.

객체 바깥에서는 이렇게 접근할 수 있습니다.

ln = LayerNorm(64)
ln.gamma

모델 부품을 self.xxx로 저장해야 하는 이유:

PyTorch가 그 부품을 모델 안에 등록하기 때문입니다.

예:

self.lm_head = nn.Linear(config["emb_dim"], config["vocab_size"])

이렇게 해야 lm_head.weight가 학습 대상 parameter로 잡힙니다.

6. 타입 힌트 문법

src/model.py에는 이런 문법이 나옵니다.

def forward(self, x: torch.Tensor) -> torch.Tensor:

뜻:

x는 torch.Tensor일 것이다.
반환값도 torch.Tensor일 것이다.

또 이런 것도 나옵니다.

targets: torch.Tensor | None = None

뜻:

targets는 torch.Tensor일 수도 있고 None일 수도 있다.
기본값은 None이다.

None은 “값이 없음”을 나타내는 Python 값입니다.

if targets is None:
    return logits

뜻:

정답 targets가 없으면 loss를 계산하지 말고 logits만 반환한다.

7. nn.Parameter

nn.Parameter는 PyTorch에게 “이 tensor는 학습되는 값이다”라고 알려주는 문법입니다.

LayerNorm에는 이런 값들이 있습니다.

self.gamma = nn.Parameter(torch.ones(normalized_shape))
self.beta = nn.Parameter(torch.zeros(normalized_shape))

torch.ones(normalized_shape)는 전부 1인 tensor를 만듭니다.

torch.ones(4)
# tensor([1., 1., 1., 1.])

torch.zeros(normalized_shape)는 전부 0인 tensor를 만듭니다.

torch.zeros(4)
# tensor([0., 0., 0., 0.])

그냥 tensor로 두면 optimizer가 학습 대상으로 보지 않을 수 있습니다.

self.gamma = torch.ones(normalized_shape)

하지만 nn.Parameter로 감싸면 학습 대상이 됩니다.

self.gamma = nn.Parameter(torch.ones(normalized_shape))

8. tensor의 mean, var

LayerNorm 구현에서 평균과 분산을 구해야 합니다.

mean = x.mean(dim=-1, keepdim=True)
var = x.var(dim=-1, keepdim=True, unbiased=False)

dim=-1은 마지막 차원을 뜻합니다.

예:

x.shape = (B, T, C)

여기서 마지막 차원은 C입니다.

dim=-1 == C 차원

keepdim=True는 평균을 낸 차원을 없애지 말라는 뜻입니다.

x.shape    = (2, 10, 64)
mean shape = (2, 10, 1)

이렇게 해야 나중에:

x - mean

이 자연스럽게 됩니다.

9. broadcasting

LayerNorm에서 이런 계산을 합니다.

x_norm = (x - mean) / torch.sqrt(var + self.eps)

여기서 shape는:

x shape:    (2, 10, 64)
mean shape: (2, 10, 1)
var shape:  (2, 10, 1)

차원이 완전히 같지 않은데 계산이 됩니다.

이유는 PyTorch가 마지막 크기 1을 자동으로 64칸에 맞춰 늘려서 계산하기 때문입니다.

이걸 broadcasting이라고 합니다.

(2, 10, 1)이 (2, 10, 64)에 맞춰져 계산됨

10. torch.sqrt, torch.tanh, torch.pow

GELU나 LayerNorm에서는 수학 함수가 나옵니다.

제곱근:

torch.sqrt(x)

하이퍼볼릭 탄젠트:

torch.tanh(x)

거듭제곱:

torch.pow(x, 3)

또는:

x ** 3

GELU tanh 근사식은 이런 모양입니다.

0.5 * x * (
    1 + torch.tanh(
        torch.sqrt(torch.tensor(2.0 / torch.pi, device=x.device))
        * (x + 0.044715 * torch.pow(x, 3))
    )
)

문법이 길어 보이지만 구조는:

입력 x에 수학 함수를 적용해서 같은 shape의 tensor를 반환한다.

입니다.

11. device=x.device

GPU를 쓰면 tensor가 GPU 위에 있습니다.

x.device

는 x가 CPU에 있는지 GPU에 있는지 알려줍니다.

새 tensor를 만들 때 입력과 같은 device에 만들어야 합니다.

torch.tensor(2.0 / torch.pi, device=x.device)

그렇지 않으면 이런 문제가 생길 수 있습니다.

x는 GPU에 있는데 새 tensor는 CPU에 있음
둘을 같이 계산하려고 해서 에러

12. nn.Linear

nn.Linear(in_features, out_features)는 입력 벡터에서 가중합을 여러 개 만들어 출력 벡터를 만듭니다.

nn.Linear(d_model, 4 * d_model)

뜻:

마지막 차원 d_model을 4*d_model로 바꾼다.

입력이:

x.shape = (B, T, d_model)

이면:

out.shape = (B, T, 4*d_model)

nn.Linear는 마지막 차원만 봅니다.

FeedForward에서는 보통 이렇게 씁니다.

nn.Linear(d_model, 4 * d_model)
GELU()
nn.Linear(4 * d_model, d_model)

shape 흐름:

(B, T, C)
-> (B, T, 4C)
-> (B, T, 4C)
-> (B, T, C)

13. nn.Sequential

nn.Sequential은 여러 layer를 순서대로 묶는 문법입니다.

self.net = nn.Sequential(
    nn.Linear(d_model, 4 * d_model),
    GELU(),
    nn.Linear(4 * d_model, d_model),
    nn.Dropout(dropout),
)

이렇게 만들면 forward에서 한 줄로 쓸 수 있습니다.

def forward(self, x):
    return self.net(x)

실제로는 아래와 같은 뜻입니다.

x = self.net[0](x)
x = self.net[1](x)
x = self.net[2](x)
x = self.net[3](x)
return x

순서대로 지나간다는 점이 중요합니다.

14. nn.Dropout

Dropout은 학습 중 일부 값을 0으로 만들어 과적합을 줄이는 layer입니다.

self.dropout = nn.Dropout(drop_rate)

사용:

x = self.dropout(x)

학습 모드에서는 일부 값이 0이 됩니다.

model.train()

평가 모드에서는 dropout이 꺼집니다.

model.eval()

테스트에서 shape만 보면 dropout은 shape를 바꾸지 않습니다.

(B, T, C) -> (B, T, C)

15. nn.ModuleList

TransformerBlock을 여러 개 만들 때 씁니다.

self.blocks = nn.ModuleList([
    TransformerBlock(...)
    for _ in range(config["n_layers"])
])

그냥 Python list와 비슷하지만, PyTorch가 내부 모듈들을 제대로 추적합니다.

좋은 방식:

self.blocks = nn.ModuleList([...])

피해야 할 방식:

self.blocks = [...]

일반 list에 넣으면 PyTorch가 모듈을 제대로 등록하지 못하는 경우가 생깁니다.

16. list comprehension

이 문법:

[
    TransformerBlock(...)
    for _ in range(config["n_layers"])
]

은 list를 만드는 짧은 문법입니다.

예:

nums = [i for i in range(3)]

결과:

[0, 1, 2]

GPTModel에서는 block 여러 개를 만들 때 씁니다.

self.blocks = nn.ModuleList([
    TransformerBlock(
        d_model=config["emb_dim"],
        n_heads=config["n_heads"],
        drop_rate=config["drop_rate"],
        qkv_bias=config["qkv_bias"],
    )
    for _ in range(config["n_layers"])
])

_는 반복 변수 이름이 필요 없을 때 관례적으로 쓰는 이름입니다.

17. for 반복문

여러 TransformerBlock을 순서대로 통과시킬 때 씁니다.

for block in self.blocks:
    x = block(x, causal_mask=True)

뜻:

self.blocks 안의 block을 하나씩 꺼내서
x를 통과시키고
그 결과를 다시 x에 저장한다.

흐름:

x
-> block 0
-> block 1
-> block 2

18. config dict 문법

GPTModel은 config dict를 받습니다.

def __init__(self, config: dict):
    self.config = config

dict에서 값 꺼내기:

config["vocab_size"]
config["context_length"]
config["emb_dim"]

예:

config = {
    "vocab_size": 1000,
    "emb_dim": 64,
}

config["vocab_size"]
# 1000

GPTModel에서는 이런 식으로 씁니다.

self.lm_head = nn.Linear(config["emb_dim"], config["vocab_size"])

19. residual connection의 +

TransformerBlock에서는 원래 입력과 결과를 더합니다.

x = x + attn_out

이것은 tensor끼리 같은 위치의 값을 더하는 연산입니다.

shape가 같아야 합니다.

x shape:        (B, T, C)
attn_out shape: (B, T, C)

FeedForward 뒤에도 똑같이 합니다.

x = x + ffn_out

이것이 residual connection입니다.

20. tuple 반환

GPTModel.forward는 상황에 따라 반환값이 달라집니다.

targets가 없으면:

return logits

targets가 있으면:

return loss, logits

이때 (loss, logits)는 tuple입니다.

result = (loss, logits)

받을 때는 이렇게 나눠 받을 수 있습니다.

loss, logits = model(idx, targets=targets)

21. isinstance

어떤 값이 특정 타입인지 확인하는 함수입니다.

isinstance(logits, tuple)

뜻:

logits가 tuple이면 True
아니면 False

generate_text_simple에서 모델 반환값이 tuple인지 확인할 때 쓸 수 있습니다.

logits = model(idx_cond)

if isinstance(logits, tuple):
    logits = logits[1]

왜 필요하냐면 모델이 어떤 상황에서는:

(loss, logits)

를 반환할 수 있기 때문입니다.

22. import torch.nn.functional as F

cross entropy loss를 직접 계산하려면 보통 이 import가 필요합니다.

import torch.nn.functional as F

그러면:

F.cross_entropy(...)

를 쓸 수 있습니다.

torch.nn.functional은 layer 객체가 아니라 함수 형태의 연산들을 모아둔 곳입니다.

23. reshape

loss 계산 전에 logits와 targets를 펼쳐야 합니다.

logits.reshape(-1, logits.size(-1))
targets.reshape(-1)

예:

logits shape:  (B, T, vocab_size)
targets shape: (B, T)

펼친 뒤:

logits shape:  (B*T, vocab_size)
targets shape: (B*T)

-1은 PyTorch에게 “이 차원은 알아서 계산해줘”라는 뜻입니다.

예:

x = torch.randn(2, 3, 4)
x.reshape(-1, 4).shape
# torch.Size([6, 4])

24. size(-1)

tensor의 특정 차원 크기를 알고 싶을 때 씁니다.

logits.size(-1)

-1은 마지막 차원입니다.

logits shape = (B, T, vocab_size)
logits.size(-1) == vocab_size

그래서 loss 계산에서:

logits.reshape(-1, logits.size(-1))

라고 쓰면 마지막 차원인 vocab_size는 유지하고, 앞 차원들을 한 줄로 펼칩니다.

25. F.cross_entropy

모델의 logits와 정답 target을 비교해서 loss를 만듭니다.

loss = F.cross_entropy(
    logits.reshape(-1, logits.size(-1)),
    targets.reshape(-1),
)

입력 모양:

logits:  (N, vocab_size)
targets: (N)

여기서 N = B * T입니다.

중요:

cross_entropy에는 softmax를 직접 적용한 확률이 아니라 logits를 넣습니다.

즉 이렇게 하지 않습니다.

probs = torch.softmax(logits, dim=-1)
loss = F.cross_entropy(probs, targets)

그냥 logits를 넣습니다.

26. slicing: idx[:, -context_size:]

generate에서 너무 긴 입력은 뒤쪽 일부만 잘라 씁니다.

idx_cond = idx[:, -context_size:]

뜻:

모든 batch에 대해
뒤에서 context_size개 token만 가져온다.

예:

idx = [[10, 11, 12, 13, 14, 15]]
context_size = 4

결과:

idx_cond = [[12, 13, 14, 15]]

문법 해석:

idx[:, -context_size:]
첫 번째 차원 `:` = 모든 batch
두 번째 차원 `-context_size:` = 뒤에서 context_size개부터 끝까지

27. slicing: logits[:, -1, :]

모델은 모든 위치의 logits를 냅니다.

logits shape = (B, T, vocab_size)

다음 token 하나를 고를 때는 마지막 위치의 logits만 필요합니다.

logits = logits[:, -1, :]

결과:

(B, T, vocab_size)
-> (B, vocab_size)

문법 해석:

첫 번째 차원 `:` = 모든 batch
두 번째 차원 `-1` = 마지막 token 위치
세 번째 차원 `:` = vocab 전체 점수

28. torch.argmax

가장 큰 값의 인덱스를 찾습니다.

idx_next = torch.argmax(logits, dim=-1, keepdim=True)

여기서:

logits shape = (B, vocab_size)

dim=-1은 vocab 차원에서 가장 큰 점수를 찾는다는 뜻입니다.

keepdim=True는 결과 차원을 유지하라는 뜻입니다.

keepdim=False: (B)
keepdim=True:  (B, 1)

generate에서 뒤에 붙이려면 (B, 1) 모양이 편합니다.

29. torch.cat

tensor를 이어 붙입니다.

idx = torch.cat((idx, idx_next), dim=1)

shape:

idx shape:      (B, T)
idx_next shape: (B, 1)

dim=1 방향으로 붙이면:

(B, T) + (B, 1) -> (B, T + 1)

즉 새 token을 뒤에 하나 붙이는 것입니다.

30. range(max_new_tokens)

generate에서는 새 token을 여러 번 붙입니다.

for _ in range(max_new_tokens):
    ...

예:

for _ in range(3):
    print("repeat")

출력:

repeat
repeat
repeat

max_new_tokens=6이면 6번 반복하고, 새 token이 6개 붙습니다.

31. NotImplementedError 지우기

템플릿에는 이런 줄이 있습니다.

raise NotImplementedError("LayerNorm.forward를 구현하세요.")

이 줄은 “아직 구현 안 됨”이라는 뜻입니다.

구현을 끝내면 반드시 지워야 합니다.

예:

def forward(self, x):
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, keepdim=True, unbiased=False)
    return self.gamma * (x - mean) / torch.sqrt(var + self.eps) + self.beta

이렇게 실제 return이 있으면 raise NotImplementedError는 남아 있으면 안 됩니다.

이 문법들을 사용해서 src/model.py를 구현한 뒤 아래 테스트를 실행합니다.
