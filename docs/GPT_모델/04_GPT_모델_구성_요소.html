1. 이 과제에서 만드는 것

이번 단계는 이전 과제에서 만든 InputEmbedding과 MultiHeadAttention을 가져와서 GPT 모델의 몸통을 조립하는 단계입니다. 새로 구현할 것은 다음 여섯 가지입니다.

구현 대상 역할 테스트가 보는 것
LayerNorm 각 토큰 벡터의 마지막 차원을 안정적인 범위로 정규화합니다. 입력과 같은 shape가 나오는지
GELU FeedForward 안에서 쓰는 부드러운 활성화 함수입니다. 입력과 같은 shape가 나오는지
FeedForward 각 토큰 벡터를 4배 차원으로 확장했다가 다시 원래 차원으로 줄입니다. (B, T, C) shape를 유지하는지
TransformerBlock LayerNorm, causal attention, FeedForward, residual connection을 묶습니다. 입력과 같은 (B, T, C)가 나오는지
GPTModel 토큰 ID를 logits로 바꾸는 전체 GPT 모델입니다. (B, T, vocab_size) logits와 loss 반환
generate_text_simple 가장 큰 logit의 토큰을 반복해서 뒤에 붙이는 greedy 생성 함수입니다. 길이가 max_new_tokens만큼 늘어나는지
이 과제의 핵심은 “내용은 바꾸되 shape는 유지한다”입니다. TransformerBlock은 입력과 출력 shape가 같아야 여러 블록을 계속 쌓을 수 있습니다.

2. GPTModel 전체 흐름

GPT 모델은 토큰 ID를 받아서 각 위치마다 “다음 토큰 후보 점수”를 출력합니다. 이 점수를 logits라고 부릅니다.

idx (B, T)
InputEmbedding: token embedding + position embedding (B, T, C)
TransformerBlock x n_layers (B, T, C)
final LayerNorm (B, T, C)
LM head Linear(C -> vocab_size) (B, T, V)

여기서 B는 batch size, T는 sequence length, C는 embedding dimension, V는 vocabulary size입니다.

문맥 벡터와 임베딩의 관계 처음 입력은 토큰 임베딩입니다. TransformerBlock을 지나면 같은 shape의 새 벡터가 나오는데, 이 벡터는 주변 토큰 정보를 반영한 문맥 벡터입니다. 다음 블록은 이 문맥 벡터를 새 입력처럼 받습니다.

3. 구성 요소별 이해

3.1 LayerNorm

LayerNorm은 각 토큰 벡터 내부의 마지막 차원에 대해 평균과 분산을 계산합니다. (B, T, C) 입력이라면 각 C차원 벡터를 따로 정규화합니다. 

mean = x.mean(dim=-1, keepdim=True)
var = x.var(dim=-1, keepdim=True, unbiased=False)
norm_x = (x - mean) / torch.sqrt(var + self.eps)
out = self.gamma * norm_x + self.beta

gamma와 beta는 학습되는 파라미터입니다. 정규화 후에도 모델이 필요하면 다시 크기를 조절하거나 이동할 수 있게 해줍니다.

3.2 GELU

GELU는 ReLU처럼 비선형성을 넣는 함수지만 더 부드럽게 변합니다. 교재 ch04는 GPT-2에서 쓰는 tanh 근사식을 소개합니다. 

return 0.5 * x * (
    1.0 + torch.tanh(
        torch.sqrt(torch.tensor(2.0 / torch.pi, device=x.device))
        * (x + 0.044715 * torch.pow(x, 3))
    )
)
torch.tensor(2.0 / torch.pi)를 만들 때 device=x.device를 맞추면 GPU에서 안전합니다. 테스트는 CPU지만 습관을 들여두면 좋습니다.

3.3 FeedForward

FeedForward는 각 토큰 위치를 독립적으로 처리하는 작은 MLP입니다. attention이 토큰 사이 관계를 섞는다면, FeedForward는 각 토큰 벡터 안의 특징을 더 풍부하게 변환합니다. 

self.net = nn.Sequential(
    nn.Linear(d_model, mult * d_model),
    GELU(),
    nn.Linear(mult * d_model, d_model),
    nn.Dropout(dropout),
)

앞에서 4배로 늘리고 뒤에서 다시 줄이기 때문에 최종 shape는 그대로 (B, T, d_model)입니다.

3.4 TransformerBlock

TransformerBlock은 GPT의 반복 단위입니다. 이 과제의 구조는 Pre-LayerNorm입니다. 즉, attention과 FeedForward 앞에 LayerNorm을 먼저 적용합니다. 

shortcut = x
x = self.norm1(x)
x = self.attn(x, causal_mask=causal_mask)
x = self.drop_resid(x)
x = x + shortcut

shortcut = x
x = self.norm2(x)
x = self.ffn(x)
x = self.drop_resid(x)
x = x + shortcut

x + shortcut이 residual connection입니다. 깊은 모델에서 정보와 gradient가 더 잘 흐르게 도와줍니다.

3.5 GPTModel

GPTModel은 전체 조립입니다. 이 과제에서는 이미 만든 InputEmbedding을 사용하면 됩니다. TransformerBlock은 causal_mask 인자를 받으므로 nn.ModuleList에 담고 직접 반복하는 편이 명확합니다. 

self.embedding = InputEmbedding(
    config["vocab_size"],
    config["emb_dim"],
    config["context_length"],
    config["drop_rate"],
)
self.blocks = nn.ModuleList([
    TransformerBlock(
        config["emb_dim"],
        config["n_heads"],
        config["drop_rate"],
        config.get("qkv_bias", False),
    )
    for _ in range(config["n_layers"])
])
self.final_norm = LayerNorm(config["emb_dim"])
self.lm_head = nn.Linear(config["emb_dim"], config["vocab_size"], bias=False)

3.6 targets가 있을 때 loss 계산

GPTModel(idx)는 logits만 반환하면 됩니다. GPTModel(idx, targets)는 (loss, logits)를 반환해야 합니다. 

logits = self.lm_head(x)

if targets is None:
    return logits

B, T, V = logits.shape
loss = nn.functional.cross_entropy(
    logits.view(B * T, V),
    targets.view(B * T),
)
return loss, logits

Cross entropy는 마지막 차원 V를 class 점수로 봅니다. 그래서 (B, T, V)를 (B*T, V)로 펴고, targets도 (B*T)로 펴서 token 단위 분류 문제처럼 계산합니다.

4. 추천 구현 순서

  1. LayerNorm.forward를 구현하고 첫 테스트만 실행합니다.
  2. GELU.forward를 구현합니다.
  3. FeedForward.__init__, FeedForward.forward를 구현합니다.
  4. TransformerBlock.__init__, TransformerBlock.forward를 구현합니다.
  5. GPTModel.__init__, GPTModel.forward를 구현합니다.
  6. generate_text_simple을 마지막에 구현합니다.

generate_text_simple의 흐름

생성 함수는 모델을 반복 호출합니다. 매번 마지막 위치의 logits만 보고 가장 큰 값을 가진 token id를 뒤에 붙입니다. 

for _ in range(max_new_tokens):
    idx_cond = idx[:, -context_size:]
    with torch.no_grad():
        logits = model(idx_cond)
    if isinstance(logits, tuple):
        logits = logits[1]
    logits = logits[:, -1, :]
    idx_next = torch.argmax(logits, dim=-1, keepdim=True)
    idx = torch.cat((idx, idx_next), dim=1)
return idx
idx[:, -context_size:]가 중요합니다. 모델의 위치 임베딩은 최대 context_length까지만 있으므로, 문맥이 길어지면 마지막 토큰들만 잘라서 넣어야 합니다.

6. 자주 막히는 곳

1. LayerNorm 분산 옵션

교재 구현과 맞추려면 unbiased=False를 사용합니다. 최신 PyTorch에서는 correction=0과 같은 뜻입니다.

2. MultiHeadAttention 선행 구현

TransformerBlock은 MultiHeadAttention을 호출합니다. 먼저 pytest tests/test_attention.py -v가 통과하는지 확인하세요.

3. tuple 반환 처리

attention이 디버깅용으로 (out, attn_weights)를 반환할 수 있습니다. 블록 안에서는 실제 출력 out만 사용해야 합니다.

4. view 전에 contiguous

이번 model.py에서는 크게 문제되지 않지만, attention 구현에서 transpose 뒤 view를 쓸 때는 contiguous() 또는 reshape()가 필요할 수 있습니다.

5. logits의 마지막 차원

lm_head의 출력 차원은 반드시 vocab_size입니다. 각 위치마다 어휘 사전 전체 토큰 후보에 점수를 매겨야 하기 때문입니다.

6. train/eval 모드

테스트는 shape 중심이라 엄격히 요구하지 않지만, generation에서는 보통 model.eval()과 torch.no_grad()를 함께 씁니다.

주의 이 문서는 구현을 돕기 위한 학습 문서입니다. 최종 코드는 반드시 현재 저장소의 함수 시그니처와 테스트 요구사항에 맞춰 작성해야 합니다.
