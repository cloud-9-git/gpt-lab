src/train.py의 loss 계산, checkpoint, sampling generation, training loop를 교재 ch05 흐름과 tests/test_train.py 기준으로 연결해서 이해하는 문서입니다.

1. 이번 과제의 위치

앞 과제까지는 GPT 모델이 idx를 받아 logits를 만들고, targets가 있으면 loss를 반환하는 구조를 만들었습니다. 이번 과제는 그 모델을 실제 사전 학습에 쓸 수 있도록 주변 유틸리티를 붙입니다.

데이터 로더 -> input_batch, target_batch -> calc_loss_batch -> backward / optimizer.step -> 주기적 평가 -> 샘플 생성 -> checkpoint 저장
구현 함수 역할 테스트 포인트
calc_loss_batch 한 배치의 다음 토큰 예측 loss 계산 scalar Tensor 반환
calc_loss_loader 여러 배치 loss 평균 계산 float 또는 scalar Tensor 반환
save_checkpoint, load_checkpoint model/optimizer/epoch/step 저장과 복원 epoch와 global_step 복원
generate temperature와 top-k를 지원하는 토큰 생성 요청한 토큰 수만큼 길이 증가
train_model 사전 학습 루프 실행 노트북/실행 흐름에서 검증
참고 범위: docs/LLM.txt의 ch05 중 5.1 텍스트 생성 모델 평가, 5.2 LLM 훈련, 5.3 디코딩 전략, 5.4 저장과 로드 흐름을 이 과제 구조에 맞게 압축했습니다.

2. 한 배치 Loss 계산

GPT 사전 학습의 정답은 별도 라벨이 아니라 입력 토큰을 한 칸 민 target입니다. 예를 들어 입력이 [A, B, C]이면 target은 [B, C, D]입니다. 모델은 각 위치에서 다음 토큰 후보 전체에 대한 점수, 즉 logits를 냅니다.

input_batch: (B, T) target_batch: (B, T) model(input_batch) -> logits: (B, T, vocab_size) cross_entropy가 원하는 모양: logits: (B*T, vocab_size) targets: (B*T)

그래서 calc_loss_batch는 세 단계로 생각하면 됩니다.

  1. input_batch와 target_batch를 device로 옮깁니다.
  2. model(input_batch)를 호출해서 logits를 얻습니다.
  3. logits와 targets를 펼쳐 torch.nn.functional.cross_entropy에 넣습니다.
def calc_loss_batch(input_batch, target_batch, model, device):
    input_batch = input_batch.to(device)
    target_batch = target_batch.to(device)

    logits = model(input_batch)
    loss = torch.nn.functional.cross_entropy(
        logits.flatten(0, 1),
        target_batch.flatten(),
    )
    return loss
주의: cross_entropy에는 softmax를 미리 적용하지 않습니다. 이 함수가 logits에 대해 softmax와 음의 로그 확률 계산을 내부에서 처리합니다.

3. Loader 평균 Loss

검증 loss는 한 배치만 보면 흔들릴 수 있으므로 여러 배치의 평균으로 봅니다. 교재 ch05의 흐름도 calc_loss_batch를 여러 번 호출해 누적한 뒤 평균을 냅니다. 

def calc_loss_loader(data_loader, model, device, num_batches=None):
    if len(data_loader) == 0:
        return float("nan")

    if num_batches is None:
        num_batches = len(data_loader)
    else:
        num_batches = min(num_batches, len(data_loader))

    total_loss = 0.0
    for i, (input_batch, target_batch) in enumerate(data_loader):
        if i >= num_batches:
            break
        loss = calc_loss_batch(input_batch, target_batch, model, device)
        total_loss += loss.item()

    return total_loss / num_batches
평가에서는 바깥쪽에서 model.eval()과 torch.no_grad()를 같이 쓰면 dropout과 gradient 기록을 끌 수 있습니다. 이 과제 주석도 검증에서 torch.no_grad() 사용을 강조합니다.

4. Checkpoint 저장과 복원

모델 가중치만 저장하면 추론은 가능하지만, 학습을 정확히 이어가려면 optimizer 상태도 필요합니다. AdamW 같은 optimizer는 파라미터별 이동 평균 등 내부 상태를 들고 있기 때문입니다.

checkpoint = { "model_state_dict": model.state_dict(), "optimizer_state_dict": optimizer.state_dict(), "epoch": epoch, "global_step": global_step, }
def save_checkpoint(model, optimizer, epoch, global_step, path):
    torch.save(
        {
            "model_state_dict": model.state_dict(),
            "optimizer_state_dict": optimizer.state_dict(),
            "epoch": epoch,
            "global_step": global_step,
        },
        path,
    )
def load_checkpoint(model, optimizer, path, device):
    checkpoint = torch.load(path, map_location=device)
    model.load_state_dict(checkpoint["model_state_dict"])

    if optimizer is not None and "optimizer_state_dict" in checkpoint:
        optimizer.load_state_dict(checkpoint["optimizer_state_dict"])

    return checkpoint.get("epoch", 0), checkpoint.get("global_step", 0)
테스트는 checkpoint 저장 후 새 모델/optimizer에 로드했을 때 epoch == 1, global_step == 10이 복원되는지 확인합니다.

5. Temperature와 Top-k Generate

generate_text_simple은 항상 가장 큰 logit을 고르는 greedy 방식입니다. 이번 generate는 temperature와 top-k를 추가해서 더 다양한 출력을 만들 수 있게 합니다.

temperature == 0 또는 0 이하

argmax로 가장 큰 logit을 고릅니다. 결정론적입니다.

temperature > 0

logits를 temperature로 나누고 softmax 후 torch.multinomial로 샘플링합니다.

top_k

상위 k개 후보만 남기고 나머지는 -inf로 마스킹합니다.

def generate(model, idx, max_new_tokens, context_size,
             temperature=1.0, top_k=None, eos_id=None):
    for _ in range(max_new_tokens):
        idx_cond = idx[:, -context_size:]

        with torch.no_grad():
            logits = model(idx_cond)

        if isinstance(logits, tuple):
            logits = logits[1]

        logits = logits[:, -1, :]

        if top_k is not None:
            top_logits, _ = torch.topk(logits, top_k)
            min_val = top_logits[:, -1].unsqueeze(-1)
            logits = torch.where(
                logits < min_val,
                torch.full_like(logits, float("-inf")),
                logits,
            )

        if temperature > 0:
            probs = torch.softmax(logits / temperature, dim=-1)
            idx_next = torch.multinomial(probs, num_samples=1)
        else:
            idx_next = torch.argmax(logits, dim=-1, keepdim=True)

        if eos_id is not None and (idx_next == eos_id).all():
            break

        idx = torch.cat((idx, idx_next), dim=1)

    return idx
batch 처리 주의: idx_next == eos_id는 Tensor입니다. batch 크기가 1인 테스트에서는 단순 비교도 통과할 수 있지만, 안정적으로는 .all() 또는 .any() 기준을 정해서 처리하는 편이 낫습니다.

6. Train Loop 흐름

교재 ch05의 학습 루프는 평범한 PyTorch 훈련 흐름입니다. 매 배치마다 loss를 계산하고, gradient를 만들고, optimizer로 가중치를 갱신합니다. 일정 step마다 train/val loss를 평가하고, epoch 끝에는 샘플 텍스트를 생성합니다.

for epoch: model.train() for input_batch, target_batch in train_loader: optimizer.zero_grad() loss = calc_loss_batch(...) loss.backward() optimizer.step() global_step += 1 if global_step % eval_freq == 0: model.eval() with torch.no_grad(): train_loss = calc_loss_loader(...) val_loss = calc_loss_loader(...) model.train() generate_and_print_sample(...)

이 과제의 train_model은 반환 타입이 list[float]입니다. 템플릿 주석도 “epoch별 train loss 리스트”를 반환하라고 되어 있으므로, 최소한 epoch마다 train loss를 기록해서 반환하면 됩니다. 필요하면 내부에서 validation loss도 출력하거나 별도 리스트로 관리할 수 있습니다.

generate_and_print_sample

tokenizer는 구현체마다 메서드 이름이 다를 수 있습니다. 이 저장소의 BPE tokenizer는 일반적으로 encode와 decode를 사용합니다. 

def generate_and_print_sample(model, tokenizer, device, start_context,
                              max_new_tokens=50, context_size=256,
                              temperature=0.8, top_k=40):
    model.eval()
    encoded = torch.tensor(
        tokenizer.encode(start_context),
        dtype=torch.long,
        device=device,
    ).unsqueeze(0)

    with torch.no_grad():
        token_ids = generate(
            model,
            encoded,
            max_new_tokens=max_new_tokens,
            context_size=context_size,
            temperature=temperature,
            top_k=top_k,
        )

    decoded = tokenizer.decode(token_ids[0].tolist())
      print(decoded.replace("\n", " "))
    model.train()

자주 틀리는 지점

  • cross_entropy 전에 softmax를 적용하는 실수
  • target_batch를 device로 옮기지 않는 실수
  • num_batches가 loader 길이보다 클 때 그대로 순회하려는 실수
  • checkpoint에 optimizer state나 global step을 빼먹는 실수
  • top-k에서 min_val shape를 (B, 1)로 맞추지 않는 실수
  • 생성 중 logits[:, -1, :]로 마지막 위치만 고르지 않는 실수
